About the Studio

Where Warm Aesthetics Meet Smart Circulation

Built as a responsive front-end prototype using HTML5, CSS3, JavaScript, localStorage, and JSON, SmartLib delivers a welcoming boutique library workflow across desktop, tablet, and mobile screens.

How to Complete a Borrow Workflow

  1. Browse Catalog: Filter books by category or shelf status on the Book Catalog page and click Borrow Book.
  2. Enter Valid Borrower Info: Provide a full first and last name separated by a space, a valid Student/Library ID (YYYY-XXXX), and a legitimate email (@gmail.com, @yahoo.com, etc.).
  3. Review & Print Receipt: Confirming generates a unique reference code (LIB-2026-XXXX) and opens the printable Receipt page.
  4. Manage & Edit Records: Visit Records to edit borrower info, print official circulation slips, mark books as Returned, extend due dates, or Cancel/Delete records.

Prototype Scope & Limitations

  • Browser-Local Storage: All books and transaction records are saved in your browser's localStorage and persist across page refreshes on this device.
  • Simulated Notifications: Email due-date alerts and ID verification are simulated for front-end demonstration.
  • Portable JSON Backup: Use Export JSON on the Records page to download a backup file, or Import JSON to restore valid records.
